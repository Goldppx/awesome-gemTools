# awesome-gemTools

一些实用的小工具。各工具的运行方法见独立 README。

| 工具 | 简介 |
| --- | --- |
| [ChatGPT Updater](tools/chatgpt-updater/README.md) | 中英双语 WPF／命令行更新器，支持并行下载。 |
| [Wardogs PWA](tools/wardogs-pwa/README.md) | 切换 messagetransfer 服务的运行状态。 |
| [PDF Watermark](tools/pdf-watermark/README.md) | 离线预览 PDF，添加文字或图片水印。 |
| [EazyLoopback](tools/eazy-loopback/README.md) | Windows 音频输入监听与增益调节。 |
