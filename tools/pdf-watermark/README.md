# PDF 水印工具（离线版）

双击 `index.html`，在新版 Microsoft Edge 或 Google Chrome 中使用。不需要安装 Python、.NET 或额外运行时，也不需要联网。打开的 PDF 和图片只在本机浏览器中处理。

## 使用

1. 点击“打开 PDF”，选择本地文件。
2. 选择文字或图片水印。文字可点击“读取字体”，允许浏览器访问本机字体列表后选择已安装的字体；若浏览器不支持该功能，仍可使用下拉框中的常见系统字体。
3. 调整字号、颜色、缩放、不透明度、位置及页面。图片可使用色度键去除指定背景色，并调整容差。
4. 用“上一页 / 下一页”检查预览，点击“导出 PDF”。浏览器会下载一个 `_watermarked.pdf` 文件，原文件不会改动。

页码格式：`1,3,5-8`，也支持中文逗号。九宫格的边距作用于靠边的格子；绝对坐标以页面左上角为原点，单位为毫米。图片在 100% 缩放时宽度为页面宽度的 30%；文字在 100% 缩放时使用所选字号。文字会作为高清透明图像嵌入 PDF，以支持本机安装的中文及其他字体。

## 体积与分发

整个 `pdf_watermark` 文件夹约 2 MB。直接复制或压缩整个文件夹即可分发，保留 `vendor` 内的许可文件。依赖 [PDF.js](https://mozilla.github.io/pdf.js/)（Apache-2.0）与 [pdf-lib](https://github.com/Hopding/pdf-lib)（MIT）；本工具主体代码按 Apache-2.0 开源；第三方库继续遵循各自许可。

已签名 PDF 在任何编辑后通常会失去原签名的有效性。加密 PDF 暂不支持。非常大的文件会受浏览器内存限制。
