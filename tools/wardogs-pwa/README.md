# Wardogs PWA 服务切换

切换 Windows 的 messagetransfer 服务：运行中则停止，未运行则启动。原脚本用于切换 Wardogs 和完美世界 CS 的使用场景。

## 使用

右键 Wardogs-PWA.bat，选择“以管理员身份运行”。查看服务操作结果后，按任意键关闭窗口。脚本只切换服务运行状态，不修改其启动类型。

需要系统已经安装 messagetransfer 服务。找不到服务、权限不足或服务拒绝启停时，请以系统报错为准；脚本中的游戏提示不代表游戏兼容性已验证。
